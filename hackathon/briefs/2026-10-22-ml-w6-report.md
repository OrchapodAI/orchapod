### Real CPU check: the evidence (M5)

**Inputs:**

- Downloaded with `huggingface_hub.snapshot_download(..., token=False, allow_patterns=[config, tokenizer, model.safetensors files])`.

**The synthetic LoRA** (`make_lora.py`, run in the quantize image):
- r 8, α 16. Every q/k/v/o/gate/up/down of every layer gets A ~ N(0, 0.02²) of shape (r, in) and B ~ N(0, 0.02²) of shape (out, r), in bf16, seed 0.
- It is written twice:
  - `tf/`: Token Factory's names, `model.layers.N.self_attn.q_proj.lora_A.weight`.
  - `peft/`: PEFT's and Unsloth's names, `base_model.model.` + the same.
- With `--merge` it also writes `merged/`: the base safetensors in f32 with W += (α/r)·B@A, plus the base's config and tokenizer files.
```python
for i in range(c["num_hidden_layers"]):
    for mod, (o, n) in shapes.items():   # q (heads·d, h), k/v (kv·d, h), o (h, heads·d), gate/up (inter, h), down (h, inter)
        name = f"model.layers.{i}.{mod}"
        lora[f"{name}.lora_A.weight"] = (torch.randn(R, n, generator=g) * 0.02).to(torch.bfloat16)
        lora[f"{name}.lora_B.weight"] = (torch.randn(o, R, generator=g) * 0.02).to(torch.bfloat16)
# adapter_config.json: {"peft_type": "LORA", "r": 8, "lora_alpha": 16, "lora_dropout": 0.0, "bias": "none", "task_type": null,
#                       "target_modules": [down_proj, gate_proj, k_proj, o_proj, q_proj, up_proj, v_proj], ...}
# merged: w[k] = w[k].float() + (ALPHA / R) * (B.float() @ A.float()) for each targeted weight; saved as f32
```
