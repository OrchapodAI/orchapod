# Video script, shot list and screenshots

Draft from the beat list in `hackathon/PLAN.md` and the interfaces in `docs/contracts.md`. Every shot that needs a live run says TODO(D8), and every number the narrator says is a `{placeholder}` read off the golden run, never a guess. PLAN.md calls the one-sentence front door the Copilot; the product calls it the Orchapod Agent.

## Rules

- Public on YouTube, English, under 3:00: this cut ends at 2:55. No music and no sound effects, no third-party marks (PLAN.md, "What the submission must contain").
- Everything on screen is a real run. Every segment that is sped up or cut (the planning wait in shot 2, the whole run in shot 3) carries a "sped up or cut" caption. STUB output is never shown as a result, and no non-Nebius GPU footage appears as Nebius (spike 4 ran on vast.ai).
- Say only what ran. The narrator reads numbers off the screen, does not round them in our favour, and reads a win rate below 50% as it is.
- Sponsor names as text, no logos; crop console shots to the content area. No key, token, email or project id in frame (not `.env`, not a terminal).

## The golden run

One real run of the golden pipeline: the Nebius docs specialist on Lane B, NVIDIA end to end on Nebius (contracts R25). It runs web-research, synth-distilabel (grounded), data-prep, unsloth-train (NVIDIA's Nemotron Nano 8B student, a 16-bit LoRA on an H100 Serverless Job), vllm-serve (base and adapter on one L40S Serverless Endpoint, keep-alive 15 minutes), judge-eval (Nemotron 3 Ultra, base against tuned), then the playground. It needs GPU quota (G2, Oct 25), a Tavily key and the hosted API, because Nebius Jobs report to a public https control URL. If the endpoint refuses the adapter, the student is judged on CPU instead (the CPU variant): there is then no endpoint and nothing for shot 5 to stream, so cut shot 5 and give its time to shot 4. Default topic, from PLAN.md: the Nebius AI Cloud and Token Factory docs, because the judges can verify the answers and the base model is unlikely to know them. The alternative is canonical intent #1 (US real-estate compliance), which fine-tunes Llama 3.2 3B on Token Factory (Lane A) and serves it the same way. Before recording, a live Nemotron 3 Super plan for it must come back with no errors; if it will not, use the topic's template card (alternative for shot 2): "Nemotron Nano 8B tuned as a Nebius docs specialist" or "Llama 3B tuned on US real-estate compliance". One click on a card runs its reduced plan (fewer pages and rows, and 5 judged questions instead of 30), so the narrated numbers then come from that smaller run.

## Recording

- One live run, recorded end to end from the first keystroke: it is the expensive part (about 20 minutes, PLAN.md). Shots 2 and 4 can be retaken on the finished run or the hosted fixture (`make demo`); record two takes of each (PLAN.md, D8). Shots 5 and 6 cannot. The Running Endpoint exists only for `keep_alive_min` (15 minutes in the docs template; a longer keep-alive needs Hari's yes, contracts R14), judge-eval runs inside that window, and `/compare` refuses the endpoint once it has passed, so take both shots in what is left of it. The executor deletes the Job when it ends, so capture the Job while it trains. The control plane deletes the endpoint at expiry; TODO(D8): untried on a live endpoint, so check the console after the take and delete it by hand if it is still up (an L40S left up costs $1.55/h). Record the voice-over afterwards, over the cut, so it describes what is on screen.
- Recording instance: the hosted app with `ORCHAPOD_ANON_SCALE=1` for the day (PLAN.md records on the hosted app), or a local instance with the address bar out of frame. The app sends no admin header, so at the default 0.1 the run cap is $0.30 and a plan whose estimate is above it is a plan error (`hackathon/LOG.md`, 2026-10-21T01:14Z). Also a funded Token Factory key, Tavily credits and, for shot 6, GPU quota. Restore the hosted scale afterwards.
- OBS Studio: one display capture, canvas and output 1920x1080 at 30 fps, hardware H.264 at about 12 Mbps, record to MKV and remux to MP4; the microphone is the only audio source, desktop audio off. Browser: a clean profile, no bookmarks bar or extensions, zoom 100%, Do Not Disturb on, no other tab.
