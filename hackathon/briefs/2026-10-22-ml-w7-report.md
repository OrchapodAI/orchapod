## 1. The stub stage
`containers/unsloth-train/Dockerfile` now starts with:
```dockerfile
FROM python:3.12-slim AS stub
WORKDIR /app
RUN pip install --no-cache-dir boto3==1.35.71
COPY packages/sdk-py/orchapod /app/orchapod
COPY containers/unsloth-train/run.py /app/run.py
CMD ["python", "run.py"]
```
- **Why only boto3:** it is the SDK's only third-party import (io.py; log.py uses urllib). run.py's STUB path imports only the stdlib and the SDK. `torch` is imported only on the non-STUB branch; unsloth, datasets, transformers and trl only inside `train()`. Same pin as the CUDA stage and the other slim nodes.
- **The CUDA stage is unchanged and still last**, so it stays the default target for CI, scripts/build-and-push-containers.sh and Nebius Jobs. `docker buildx build --call=targets -f containers/unsloth-train/Dockerfile .` lists `stub` and `(default)`. With BuildKit, a default build skips the unused stub stage (the legacy builder would also build it: harmless, about 6 s).
- `docker buildx build --call=check` reports one warning, the pre-existing `InvalidBaseImagePlatform` (the CUDA base is amd64-only, on this arm64 Mac). The base commit's Dockerfile gives the same; the new stage adds none.

## For qa-w8: the exact build flag
From the repo root, build unsloth-train, and only unsloth-train, with `--target stub`:
```

```
Every other node builds as today (no `--target`).
- `MUST_REGISTER` for unsloth-train should be `("lora_adapter",)`: `merged_model` exists only with `merge`, and templates 4 and 5 set `merge: false`.

## Concerns
- A `:dev` built from the stub stage has no torch. Without STUB, unsloth-train would stop at `import torch` (ModuleNotFoundError, exit 1), a safe failure.
- Without STUB, gpu nodes never run on LocalDocker anyway: they go to the GPU provider, which pulls the full CUDA image from GHCR. The stub-only `:dev` cannot reach a real run.
- The CUDA (default) stage was not built here: it is about 20 GB of amd64. Its lines are unchanged, CI builds it, and `--call=targets` shows it is still the default.
